DeviceIdentity

object DeviceIdentity

Identifies the current user by their device, so no username or password is needed (US 9.1).

The identifier is Android's Settings.Secure.ANDROID_ID, which is unique per device, user and app signing key, and survives app reinstalls on Android 8.0+. It is used directly as the user's Firestore document ID.
